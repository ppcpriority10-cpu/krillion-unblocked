# Krillion Unblocked — Free Daily Browser Games

Play Krillion Unblocked and seven free daily browser games: Krillion (daily +
Unlimited), Noillirk, Krillion City, Word Hunt, What's Your Guess?, Colour Memory and
Sequence. No login, no download — new challenges every day.

Live site: https://krillionunblocked.com

## Run locally

```bash
bun install
bun run dev        # http://localhost:3000
```

`bun` is preferred (`bun.lock` is committed); `npm install` / `npm run dev`
work too. Node 20+ is required.

## Deploy

See [DEPLOY.md](DEPLOY.md). Recommended: import this repository on Vercel
(Next.js preset, `bun install` / `bun run build`).

## Stack

Next.js 16 + React 19 + Tailwind 4 + shadcn/ui + Prisma (SQLite).
